# Gold Ore Ball Mill Product Page Research

## Page structure references

- HXJQ ball mill page: https://www.hxjq-crusher.com/products/ball-mill.html
  - Useful structure: headline metrics, wet/dry and discharge types, operating principle, advantages, technical table, customer cases and service CTA.
- Tongli wet ball mill page: https://www.cementl.com/product/wet-ball-mill/
  - Useful product language: slurry transport, dust reduction, liner/media selection, drainage and maintenance questions.
- JXSC wet pan mill page: https://www.jxscmachine.com/rock-crusher/wet-pan-mill/
  - Useful comparison context for deciding when a wet pan mill is more appropriate than a continuous ball mill.

## Specification references

- HXJQ and Hengxing public ball mill tables were used only as preliminary reference ranges for the model table on the product page.
- Final capacity, power, product size and model selection must be confirmed against ore hardness, feed distribution, target P80, circulating load and site conditions.
