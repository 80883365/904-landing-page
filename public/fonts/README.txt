Place your local font files in THIS directory (/public/fonts/).

The site's @font-face declarations (in src/styles/global.css) reference
the locally stored Roboto and Roboto Slab files in this directory.
these exact filenames:

  NotoSans-Regular.woff2          (400)
  NotoSans-Medium.woff2           (500)
  NotoSans-Bold.woff2             (700)
  NotoSansDisplay-Medium.woff2    (500, display/headings)
  NotoSansDisplay-Bold.woff2      (700, display/headings)
  NotoSans-CondensedBlack.woff2   (800, eyebrows / big numbers)

WHY THESE FONTS
  They match the design DNA extracted from the reference site (Noto Sans
  family). The "Noto Sans Condensed Black" weight is used for the strong,
  uppercase eyebrow labels and large stat numbers.

WHERE TO GET THEM (free, open license — SIL Open Font License)
  Download from Google Fonts: https://fonts.google.com/noto/specimen/Noto+Sans
  Or directly from the Noto project on GitHub.
